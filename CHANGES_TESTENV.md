# Тестовый стенд: настоящий бот против фейкового Telegram

## Зачем

`pytest` проверяет диспетчер в процессе: логику и права — да, поведение «как в Telegram» — нет.
Не покрывались polling, фоновые циклы (напоминания, автоотмена, приглашения на ОС), порядок
сообщений и правки на месте. Ровно на этом и возникали замечания при ручном тесте.

## Что добавлено

| Файл | Роль |
|---|---|
| `tools/fake_telegram.py` | HTTP-сервер Bot API + управляющий API. Понимает `form-urlencoded` (aiogram шлёт именно его) и JSON |
| `tools/sim.py` | запускает **реальный `python -m bot`** с `BOT_API_BASE`, проигрывает сценарий, печатает переписку |
| `tools/scenarios/ticket.json` | запись на занятие: три шага билета + три отказа (короткий текст, «сделайте за меня», «ничего») + чек-лист |
| `tools/scenarios/roles.json` | `/term`, `/role` кнопками, `/roles`, `/kpi` |
| `bot/__main__.py` | `BOT_API_BASE` — подмена Bot API только для тестов; по умолчанию поведение не меняется |

## Как запускать

```bash
.venv\Scripts\python.exe tools/sim.py --scenario tools/scenarios/ticket.json
.venv\Scripts\python.exe tools/sim.py --scenario tools/scenarios/roles.json --transcript out.json
```

Сценарий — JSON со шагами: `command`, `say`, `tap`, `tap_label`, `tap_first`, `expect`, `sleep`.
`tap_label` ищет кнопку по тексту в ответе на предыдущий ввод, поэтому фоновые уведомления
не сбивают навигацию.

## Что найдено сразу

- **Фейковый API не понимал form-urlencoded** — aiogram шлёт формы, а не JSON. Симптом:
  бот «молчит», `chat_id=0`, пустые тексты. После фикса — 15/15 шагов проходят.
- **Главное меню координатора перегружено**: 12 кнопок в одном экране, среди них «Создать
  занятие», «Отчёты менторов», «Сводка», «Все занятия».
- **`/start` начинается с «бот обратной связи программы»** — про менторки только в третьем
  абзаце. Для первокурсника первое сообщение не о том.
- Чек-лист и `/mysessions` — уже исправлены в `CHANGES_UX_FIXES.md`, сценарии это фиксируют.

## Проверено

- `pytest`: 96 тестов.
- Сценарий `ticket.json`: 15/15 шагов.
- Сценарий `roles.json`: 8/8 шагов.
