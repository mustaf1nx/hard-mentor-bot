# Обновление: отчёты менторов и загрузка материалов

## Что изменено

### Еженедельные отчёты менторов
- Добавлена таблица `mentor_weekly_reports`.
- Один отчёт на одного ментора на одну неделю; повторная отправка обновляет текст.
- Ментор может выбрать текущую или прошлую неделю через `/mentorreport` или кнопку «📝 Отчёт ментора».
- Бот автоматически показывает статистику по занятиям выбранной недели.
- Координатор/руководитель открывает `/mentorreports` или «📋 Отчёты менторов».
- Руководство видит `сдали X/Y`, список не сдавших и каждый отчёт отдельно.
- После сохранения отчёта руководство получает Telegram-уведомление. Сначала фиксируется БД, затем отправляется уведомление: ошибка доставки не теряет отчёт.

### Банк материалов
- После успешной загрузки PDF/DOCX мастер больше не закрывается.
- Следующий файл можно отправить сразу с теми же настройками.
- Добавлены кнопки «➕ Загрузить ещё», «🔄 Изменить тип / доступ», «📚 Открыть банк темы», «✅ Готово».
- Ошибка неподдерживаемого формата теперь называет файл и явно говорит, что разрешены PDF/DOCX; PPTX нужно экспортировать в PDF.

### Документация
- Обновлён основной `README.md` для команды.
- Обновлён `MENTORING_GUIDE.md` и технический README.

## Railway
Новых обязательных переменных окружения нет. Существующую БД удалять не нужно. Новая таблица создаётся автоматически через `Base.metadata.create_all()` при старте.
