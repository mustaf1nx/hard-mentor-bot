# Изменения: отдельный список менторов и быстрый импорт

## База и роли

`bot/db.py`: модель `Mentor`, внешний ключ на `users.telegram_id`, автоматическая однократная миграция с маркером в `meta`. Существующие таблицы и `users.role` не удаляются.

`bot/repo.py`, `bot/config.py`, `bot/middleware.py`: роль ментора, список для выбора и права берутся из `mentors`; руководство остаётся в `LEAD_IDS` / `COORDINATOR_IDS`. Пакетные операции используют одну транзакцию и защиту от дубликатов. Неоднозначные usernames не выбираются наугад.

## Команды

`bot/mentor_refs.py`: разбор списков ID, usernames и t.me-ссылок; лимит 1000 записей, проверка значений и повторов.

`bot/handlers/staff.py`: массовые `/addmentor` и `/delmentor`, импорт UTF-8 `.txt` через подпись или ответ на файл, подробный отчёт, администраторские проверки. Размер файла ограничен и до, и во время скачивания. Обычные пользователи не могут запускать скачивание для импорта.

`bot/__main__.py`, `bot/texts.py`: меню административных команд и справка RU/EN.

## Работа с большим списком и удаление

`bot/views.py`, `bot/handlers/feedback.py`: страницы в `/mentors`, выборе ментора для обращения и назначении ответственного; отменены прежние ограничения первыми 20/30 людьми. Нельзя выбрать удалённого ментора по старой кнопке.

`bot/notify.py`, `bot/reports.py`: перед уведомлением назначенного исполнителя проверяются действующие права. Удаление через SQL также учитывается; при отсутствии прав дальнейшие уведомления направляются руководству. При удалении командой активные назначения обычного ментора снимаются, закрытая история сохраняется.

## Инструкции и проверки

`MENTOR_IMPORT_GUIDE.md`: деплой существующего проекта без смены переменных, команды, `.txt`, прямой SQL и ограничения.

`sql/bulk_add_mentors.sql`: массовое добавление по usernames с результатом для каждого имени.

`tests/test_mentors.py`: дополнительные сквозные тесты. `tests/offline_mentor_checks.py`: автономные проверки ядра на SQLite. Точный результат и ограничения текущего прогона — в `VALIDATION_MENTORS.md`.
