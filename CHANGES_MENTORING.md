# Изменения: менторки, подготовка и банк материалов

Основа — `hard-mentor-bot-mentors-bulk.zip`, с сохранением предыдущего массового управления менторами.

## Новая функциональность

- Координатор/руководитель создаёт занятие и назначает ведущего из `mentors`.
- Предметы и темы переиспользуются; списки предметов, тем, менторов, занятий и участников разбиты на страницы.
- Именной входной билет: слот, вопрос, самостоятельная оценка тем, открытые рекап-гайды.
- Сохранение ответов после каждого нажатия; изменение вопроса, снятие записи и повторная запись без дублей.
- Копия чек-листа на занятии защищает исторические ответы от изменения общего шаблона.
- Банк PDF/DOCX: рекап или материал, открытый или только для команды, скрытие автором/координатором.
- Личный список занятий ведущего, индивидуальные ответы студентов и подсчёт самооценок по пунктам.
- Посещаемость, завершение занятия и загрузка материалов с автоматическим выбором предмета и темы.
- Постоянная очередь напоминаний, сообщения о нулевой записи и об удалённом из списка ведущем.
- Ручная отмена координатором, перенос/смена ведущего будущих занятий с сохранением записей.
- Сводка за всё время и TXT-отчёт; обращения остаются в отдельной сводке `/report`.
- Новая навигация имеет приоритет перед текстом старых анкет, чтобы кнопки не сохранялись как ответы на обращения.

## Новые таблицы

`mentor_subjects`, `mentor_topics`, `topic_checklists`, `mentoring_sessions`,
`session_bookings`, `learning_materials`, `mentoring_notifications`.

Деструктивной миграции нет. Существующие `users`, `mentors`, `tickets`, `notes`, `meta`
не удаляются и не заменяются. Новый код не использует legacy `users.role` для выдачи прав.
Данные менторок не записываются в `tickets` и не создают связей с авторами анонимных обращений.

## Файлы

- `bot/db.py` — новые модели, создание через существующий `init_db()`.
- `bot/mentoring/service.py` — правила, права, запросы, валидация.
- `bot/mentoring/jobs.py` — формирование уведомлений и проверки актуальности.
- `bot/mentoring/reminders.py` — доставка, повторные попытки, цикл.
- `bot/mentoring/ui.py` — карточки, клавиатуры, разбиение длинных сводок.
- `bot/handlers/mentoring.py` — команды, формы, кнопки.
- `bot/app.py`, `bot/__main__.py`, `bot/views.py`, `bot/texts.py` — подключение раздела и обновление меню.
- `tests/offline_session_checks.py` — проверки ядра на реальном SQLite/SQLAlchemy.
- `tests/test_sessions.py` — сценарии полного диспетчера для среды с установленными зависимостями.

## Границы этой версии

Расписание вводится вручную в боте; импорта из внешнего календаря и заранее заполненных
занятий нет. Проверка знаний не проводится: чек-лист — самооценка. Никаких дополнительных
ролей «респондента» или исключений для первых занятий нет. ИИ-резюме, внешние API,
распознавание документов и обязательная модерация материалов не добавлялись.

Описание проверок и их ограничения — `VALIDATION_MENTORING.md`.
