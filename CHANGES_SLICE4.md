# Слайс 4: сводка для администрации

Тот самый экран «общее состояние менторства» — без чтения таблиц и без вопросов координатору.

## Где открыть

- `/dashboard` (или `/svodka`);
- кнопка **📊 Сводка** в разделе «⚙️ Управление».

## Шесть блоков

| Блок | Что внутри |
|---|---|
| **Где мы** | триместр, номер недели, дата и часовой пояс |
| **1. Менторки** | проведено / запланировано / отменено, уникальные студенты |
| **2. Цикл по предметам** | замкнут у N из 6; по каждому: материал · слот · менторка · ОС · Банк |
| **3. Люди** | менторов в реестре, без роли на триместр, перегруз (>3 слотов/нед) |
| **4. Обращения** | открыто и просрочено по SLA |
| **5. Долги** | менторки без материалов, менторки без формы ОС |

С каждого блока — кнопки перехода: **Менторки · Цикл · Люди · Долги · Обращения · CSV**.

## Что показывает каждый экран

- **Менторки** — последние 15 занятий: статус, дата, записи, сколько собрали ОС, сколько материалов.
- **Цикл** — таблица по предметам, где видно, на каком шаге рвётся: нет материала, нет слота,
  менторка не проведена, нет ОС или ничего не положено в Банк.
- **Люди** — кто не сдал отчёт за неделю, с **никами** (а не ID), и кто перегружен.
- **Долги** — проведённые без материалов и без формы ОС, плюс отмены с причинами.
- **CSV** — выгрузка занятий триместра: дата, статус, предмет, тема, ментор, записи, ОС,
  материалы, причина отмены. Разделитель `;`, кодировка UTF-8 с BOM — Excel открывает сразу.

## Что видно на скриншоте и стоит поправить дальше

- Кнопки навигации дублируются под каждым блоком — на телефоне это 7 кнопок каждый раз.
- Цикл считает «замкнуто» строго: нужны материал **и** ОС **и** запись в Банк по одному предмету.
  Если материал есть, а проведённых менторок не было, предмет честно считается незамкнутым.
